# 浙江师范大学51天学习打卡

逐题打卡、周日集中补做与每周滚动顺延、独立备注、本机保存与备份导入导出。

2026-10-29至2026-12-18；628项专业课、200项英语一、153项政治任务。依据最新51天Word。

Render构建：`python3 build.py`，发布目录：`dist`。构建校验压缩包SHA256。

记录只保存在浏览器，不上传到公开仓库，不自动跨设备同步。旧版记录保留。

周日补做规则：未完成专业课集中到最近的周日；周日未完成的继续顺延到下个周日。旧版工作日欠题在首次打开时自动归拢。完成、备注、任务ID及旧备份保持兼容。最后一个计划内周日之后保留待安排，不推到考试日。
