## 后端部署

1. 控制台函数列表没有创建或上传入口。使用 HBuilderX 打开准备好的上传项目，登录用户自己的 DCloud 账号，在 uniCloud-alipay 目录关联 study 空间；将 study-sync 普通云函数上传。index.js 和 package.json 必须位于函数根目录。使用平台当前支持的 Node.js 运行环境。没有第三方依赖。不要把 study-sync.zip 误传到云存储或前端托管，它们不会执行云函数。
2. 创建三个集合 `study_sync_progress`、`study_sync_sessions`、`study_sync_login_limits`，应用 database 目录中对应的权限 schema，禁止客户端直接读写。云函数通过服务端数据库访问数据。
3. 在本机浏览器打开 `账号设置.html`，选择专用于学习网站的同步账号和至少12字符的密码。页面不联网，下载 study-sync-env.json，只有账号及 PBKDF2-SHA256（600000轮）的盐和摘要，不含原始密码。将 username、salt、hash 分别配置为远程环境变量 STUDY_USERNAME、STUDY_PASSWORD_SALT、STUDY_PASSWORD_HASH。不要发送到聊天或提交到 Git。更换摘要会撤销旧登录。
4. 在控制台给云函数配置 HTTP 访问路径 `/study-sync`，获取完整 HTTPS URL。
5. 只把这个公开 URL 填入 sync/config.js：`window.STUDY_CLOUD_CONFIG={provider:'unicloud',url:'完整HTTPS地址'};`。前端不要包含密码、摘要或云管理密钥。
