# Render 学习网站的跨设备同步

使用现有 Render 静态网站，并通过 uniCloud 支付宝云的 study 空间保存账号对应的进度。原网址和浏览器存储键保持不变。云函数、数据库权限和远程账号配置已接入；Render 前端随本次提交发布。

在网站“备份与设置”登录相同学习账号。首次登录明确选择“合并本机与云端记录”或“使用云端记录”。手机和电脑分别登录后可以继续同一份进度。未登录或离线时仍保存在本机。

保存、重新回到页面及手动点击会触发同步。页面可见时每10分钟检查云端。通过修订号避免两台设备直接覆盖整份数据；三方合并保留独立修改、取消完成、清空笔记和删除改期。带时间戳的同一操作保留较新版本，同一条笔记的并发修改保留正在提交设备的版本。最近5份合并前本机快照可以导出。

仅启用一个个人学习账号，不开放公众注册。密码验证使用 PBKDF2-SHA256；云端只配置盐和验证摘要。30天登录凭据在数据库中仅保存哈希。退出登录撤销当前凭据，更换密码配置使旧登录失效。客户端不能直接访问数据库；写入通过云函数检查账号与修订号。

支付宝云默认网关会拦截 OPTIONS。客户端使用 HTTPS 简单 POST（text/plain，JSON内容），将登录凭据放入请求体；云函数也兼容 Authorization 请求头。原网址的 Origin 与返回的跨域许可一致，其他来源拒绝访问。请求体不写日志。

免费空间每月需手动续期；超过免费额度时保留本机记录，不自动开通付费。单份同步数据限约900KB，过大时提示导出备份。完整接入说明见 unicloud/接入步骤.md。

已通过本地合并、两设备模拟、账号隔离、登录过期恢复及后端模拟数据库检查；原网站浏览器回归检查通过。真实 Render 来源到 uniCloud 的浏览器登录校验已验证。尚未使用用户真实密码完成两个设备的实际登录与数据往返；首次真实登录后应确认“已同步”再切换设备。

Supabase 是未启用的备用适配器；schema.sql 仅供该适配器使用。账号配置文件、.env、个人密码与管理密钥不得提交到仓库。
